# Changelog

The release notes for each version of Ready Up are in two places, and they are the same notes:

- **[Changelog in the docs](https://docs.autotournament.gg/reference/changelog/ready-up)**: every version, newest first.
- **[GitHub releases](https://github.com/Auto-Tournament/ready-up/releases)**: the notes and the downloads for each version.

The GitHub release is the source of truth. The docs changelog is generated from it, so this file does not repeat the notes. See [docs/RELEASING.md](docs/RELEASING.md) for how a release is cut.
