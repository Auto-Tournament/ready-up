# Practice guides

CS2 map annotation files. Practice mode's `.menu` shows them as lineups on their map: click one to stand on the spot, already aimed. The menu also says how to throw it.

The plugin reads every `*.txt` here (installed as `plugins/practice/guides/`) and keeps the ones whose `MapName` is the current map. To add another guide, put its annotation file in this folder. Each Workshop guide is one `.txt` file in `steamapps/workshop/content/730/<id>/`.
